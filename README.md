# PinkDream
## Un comercio electrónico para pequeños emprendimientos que quieran digitalizar sus servicios. 

**Tecnologías:**
* Angular
* Bootstrap
* TypeScript

 **Principales funciones:**
* Carrito de compra.
* Log in / Sign in
* Catalogo de productos.
* Zona usuario con lista de pedidos.
* Zona ADMIN para editar, subir o eliminar productos.
